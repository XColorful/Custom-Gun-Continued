# 隐藏提示框指令
> wiki 版本：`0.0.1`.0

## 服务端指令

### 设置隐藏提示框部件
> _/customgun hide_tooltip_part [target] [mask]_

对目标实体手持枪械应用提示框隐藏遮罩
- `target`（目标选择器）：目标实体列表
- `mask`（整数）：提示框部件位掩码

# English
> wiki verison: `0.0.1`.0

## Server command

### Set hidden tooltip parts
> _/customgun hide_tooltip_part [target] [mask]_

Apply a tooltip hide mask to the held gun of target entities
- `target` (Target selector): Target entity list
- `mask` (integer): Tooltip part bitmask
