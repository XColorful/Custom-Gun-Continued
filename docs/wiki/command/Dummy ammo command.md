# 虚拟子弹指令
> wiki 版本：`0.0.1`.0

## 服务端指令

### 设置虚拟子弹数量
> _/customgun dummy [target] [dummyAmount]_

设置目标实体手持枪械的虚拟子弹数量
- `target`（目标选择器）：目标实体列表
- `dummyAmount`（整数）：虚拟子弹数量（≥0）

# English
> wiki verison: `0.0.1`.0

## Server command

### Set dummy ammo count
> _/customgun dummy [target] [dummyAmount]_

Set the dummy ammo count of the held gun for target entities
- `target` (Target selector): Target entity list
- `dummyAmount` (integer): Dummy ammo count (≥0)
