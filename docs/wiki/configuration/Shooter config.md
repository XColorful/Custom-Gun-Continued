# 射手配置
> wiki 版本：`26.11.36.1`.1

路径：`shooter`
- `CreativeModeInfiniteFeed`（bool）：是否启用创造模式无限子弹供应
- `EnableWeightModifier`（bool）：是否启用重量修饰，关闭后枪械重量不影响移速
```toml
[shooter]
	CreativeModeInfiniteFeed = true
	EnableWeightModifier = false
```

# English
> wiki version: `26.11.36.1`.1

Path: `shooter`
- `CreativeModeInfiniteFeed` (bool): Whether to enable infinite ammo supply in Creative Mode
- `EnableWeightModifier` (bool): Whether to enable the weight modifier; when disabled, gun weight does not affect movement speed
```toml
[shooter]
	CreativeModeInfiniteFeed = true
	EnableWeightModifier = false
```
