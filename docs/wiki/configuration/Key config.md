# 按键配置
> wiki 版本：`26.10.34.1`.7

路径：`key`
- `HoldToAim`（bool）：是否按住右键来保持瞄准
- `AimSwitchToFirstPerson`（bool）：是否在瞄准时切换到第一人称视角
- `RevertAimPerspective`（bool）：是否在取消瞄准时恢复视角
- `HoldToProne`（bool）：是否按住爬行键来保持趴下
- `HoldShootPreventBolt`（bool）：是否在按住射击键时不自动拉栓
- `AutoReload`（bool）：是否在枪械空仓时自动换弹
- `ShootToReload`（bool）：是否在空仓状态下射击时触发换弹
```toml
[key]
	HoldToAim = false
	AimSwitchToFirstPerson = true
	RevertAimPerspective = true
	HoldToProne = false
	HoldShootPreventBolt = true
	AutoReload = false
	ShootToReload = true
```

# English
> wiki version: `26.10.34.1`.7

Path: `key`
- `HoldToAim` (bool): True if you want to hold the right mouse button to aim
- `AimSwitchToFirstPerson` (bool): Whether to switch to first-person view while aiming
- `RevertAimPerspective` (bool): Whether to revert the perspective upon canceling aim
- `HoldToProne` (bool): True if you want to hold the prone button to prone
- `HoldShootPreventBolt` (bool): Whether to prevent auto-bolting while holding down the shoot key
- `AutoReload` (bool): Whether to reload automatically when the chamber is empty
- `ShootToReload` (bool): Whether to trigger reload when shooting with an empty chamber
```toml
[key]
	HoldToAim = false
	AimSwitchToFirstPerson = true
	RevertAimPerspective = true
	HoldToProne = false
	HoldShootPreventBolt = true
	AutoReload = false
	ShootToReload = true
```
