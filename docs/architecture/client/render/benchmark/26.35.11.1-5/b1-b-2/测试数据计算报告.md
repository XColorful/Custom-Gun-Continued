# 测试数据计算报告（CGC 1.20.1 · b1-b-2：光影下的烘焙 A/B）

**数据**：本目录 6 次独立启动，每次 5 步：空手 / ak47 / ak47+光影 / 满配 / 满配+光影。
- 文件 `cgc1 (1)–(3)`：`StaticBake.ENABLED = true`（烘焙开，n=3）
- 文件 `cgc1 (4)–(6)`：`StaticBake.ENABLED = false`（烘焙关，n=3）

**口径**：帧时间 = 1000 / FPS；两组各自统计，配对差按文件序号一一对应（1↔4、2↔5、3↔6）。光影为 ComplementaryReimagined r5.9.3（HIGH），只测第一人称，不测 multi。
**环境**：GTX 1660 SUPER / i5-9400F / 1080p165；Forge 47.4.23 + Embeddium + Oculus + `cgccshader`；超平坦虚空、渲染距离 2；见 [标准.txt](./标准.txt)。
**复现**：`python analyze.py`。

## 2. 配对差（烘焙关 − 烘焙开，正数 = 烘焙省下）

|场景|差值|比例|逐次|
|---|---:|---:|---|
|ak47（无光影）|0.340 ± 0.049 ms|**25.7%**|[0.285, 0.379, 0.354]|
|ak47 + 光影|0.037 ± 0.043 ms|**0.6%**|[0.042, −0.008, 0.077]|
|满配（无光影）|1.636 ± 0.011 ms|**55.2%**|[1.640, 1.644, 1.623]|
|满配 + 光影|**0.518 ± 0.462 ms**|**6.9%**|[0.177, 0.334, 1.044]|

- **无光影 A/B 与 `26.35.11.1-5` 完全一致**：ak47 CGC 0.204（交接 0.202）、满配 0.548（交接 0.540）；关烘焙的 0.540 / 2.179 也与 B1-b 前的 0.584 / 2.199 吻合。这是对两批数据口径的一次交叉验证。
- **光影下烘焙仍然生效**：满配 7.520 → 7.001 ms（−0.52 ms，−6.9%），1% low 114.8 → 139.3（+21%）；三次配对全为正。
- **光影下收益被光影包淹没**：帧时间由 0.98 / 1.33 ms 涨到 6.5 / 7.0 ms，CGC 的 CPU 成本（0.2–0.55 ms）只占 3%–8%。ak47 的差值（0.037 ± 0.043）落在噪声内，但三次里两次为正、且 1% low 明确改善（135.1 → 149.0）。
- 这不是「烘焙没生效」：关掉烘焙每一项都会变慢或持平，没有一项更快。

## 3. 结论

1. **光影下第一人称烘焙路径可用且有收益**，但满配只有约 7%，ak47 在噪声内——光影场景的帧时间由光影包主导，不是 CGC 优化的目标场景。
2. 无光影下的收益（26% / 55%）与上一批一致，本批没有引入回归。
3. 光影下要分离 CGC 的 CPU 成本，需要按 pass 计时或换更轻的光影包；用整帧差只能看量级。
4. **本报告只统计帧时间**；光影下的画面（枪体、瞄具、镜内遮罩、准心、手臂）仍需按 [B1-b 验收清单](../../refactor/b1b-first-person-bake.md#验收清单人工开--关光影各一次)人工确认。

## 4. 说明

- 满配+光影的「关」组有一次 8.07 ms 离群（第 6 次启动），使 sd 偏大；去掉它后差值为约 0.24 ms（−3.2%）。三次配对的方向仍一致。
- 开关光影会重建全部分块网格（顶点格式随光影扩展），属于一次性开销；每次记录在切换后 10 s 开始，不计入稳态。
- ak47+光影 第 2 次配对 −0.008 ms 是唯一的负值，量级 8 µs，属测量噪声。
