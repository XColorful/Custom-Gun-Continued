# 配置指令
> wiki 版本：`0.0.1`.0

## 服务端指令

### 切换配置项
> _/customgun config [configKey] [state]_

切换指定配置项的状态
- `configKey`（枚举）：配置项名称
	- `defaultTableLimit`
	- `serverShootNetworkCheck`
	- `serverShootCooldownCheck`
- `state`（bool）：配置项状态

# English
> wiki verison: `0.0.1`.0

## Server command

### Toggle config
> _/customgun config [configKey] [state]_

Toggle the state of the specified config key
- `configKey` (enum): Config key name
	- `defaultTableLimit`
	- `serverShootNetworkCheck`
	- `serverShootCooldownCheck`
- `state` (bool): Config key state
