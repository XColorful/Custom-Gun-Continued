## 根因

`tacz:minigun` 的模型里有 `laser_beam` 骨骼（各 laser 配件也有，所以普通枪不触发），走 `BeamRender` 画加性混合光束：

- 写入端 [BeamRender.java:100](core/src/main/java/dev/xcolorful/customgun/client/renderer/model/BeamRender.java:100) 只写 Position/Color/UV0/UV2；
- 读取端 [ClientRenderRegistry.java:46](core/src/main/java/dev/xcolorful/customgun/client/init/registry/ClientRenderRegistry.java:46) 在 1.21.11 移植时（commit `6a5fdb5c`）被换成 `RenderTypes.entityTranslucent(...)`，其顶点格式是 `ENTITY`，要求 **UV1(overlay) + Normal** → `Missing elements in vertex: UV1, Normal`。

那次替换是为了绕开失效的自定义管线（`core/position_color_tex_lightmap` 在 1.21.10 被 vanilla 删除，且注册它会在资源重载预编译时抛异常导致启动黑屏，所以加了 `if (true) return;`）——正是你 docs 里记的那笔遗留（`docs/deprecated/prompt/single/#32-render-issue-1.md:556`）。

## 改动（单文件，+26/-8）

[ClientRenderRegistry.java](core/src/main/java/dev/xcolorful/customgun/client/init/registry/ClientRenderRegistry.java)：

- `LASER_BEAM_PIPELINE` 着色器换成 `core/particle` —— 它就是被删掉的 `position_color_tex_lightmap` 的现代等价物（`particle.vsh` 里同样一句 `vertexColor = Color * texelFetch(Sampler2, UV2/16, 0)`），snippet 换成 `MATRICES_FOG_SNIPPET`（`particle.fsh` 调 `apply_fog`，需要 Fog uniform）；
- 用 `RenderType.create + RenderSetup.builder(...)` 恢复 `LASER_BEAM` / `LASER_BEAM_ENTITY` 两个专用 RenderType（VIEW_OFFSET_Z_LAYERING + ITEM_ENTITY_TARGET + LIGHTMAP / texture，保留加性混合与无剔除），`getLaserBeam()` 回到设计文档写的“专用 RenderType、加性混合、无剔除”；
- 删掉 `if (true) return;`，两个管线重新注册（`IrisCompat.registerRenderPipelines` 那行也顺带复活了，之前被它挡死）。

副作用要说清楚：**1.21.10 起这个光束其实一直画不出来**（着色器缺失 → 编译出 invalid program → 静默不绘制），所以这次不只修崩溃，也把 1.20.1 的激光发光效果恢复了。
