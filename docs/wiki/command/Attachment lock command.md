# 配件锁指令
> wiki 版本：`0.0.8`.1

## 服务端指令

### 设置配件锁
> _/customgun attachment_lock [target] [AttachmentLock]_

对目标实体手持物应用配件锁状态
- `target`（目标选择器）：目标实体列表
- `AttachmentLock`（bool）：配件锁状态

# English
> wiki verison: `0.0.1`.0

## Server command

### Set attachment lock
> _/customgun attachment_lock [target] [AttachmentLock]_

Apply attachment lock status to target entities' main hand item
- `target` (Target selector): Target entity list
- `AttachmentLock` (bool): Attachment lock status
