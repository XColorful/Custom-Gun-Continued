测试方式：
- CGC端tacz_default_gun补TaCZ内置第一人称animations动画（对齐TaCZ）
- CGC客户端配置关掉枪械HUD
- 超平坦虚空预设，和平，/tp @s 8.5 ~ 8.5 0 0
- 禁用昼夜更替，禁用天气循环，/time set 5000
- 渲染距离2，模拟距离5，全屏
- 保持第一人称视角
- 启动任意端，等Afterburner游戏内FPS到1100~1300（预热）
- Sodium降低帧率-最小化时
- Iris/Oculus最大阴影距离Disabled
- 全称关游戏内F3
- 清空tacz:ak47子弹（/cgc debug setMagAmmo 0后再开一枪，再/tp @s ~ ~ ~ 0 0固定视角）
- 1. DebugKey自动跑3次换弹，10秒后自动停止
- 清空快捷栏（/clear），第一人称裸配枪械（/function customgun:testgun）
- 2. DebugKey自动跑3次换弹，10秒后自动停止
- 清空快捷栏（/clear），第一人称满配枪械（/function customgun:testgun_full）
- 3. DebugKey自动跑3次换弹，10秒后自动停止

说明：
- 每种测试方式都是提前做好地图，保证启动游戏第一次进存档就是测试条件及角色朝向
- tacz:ak47和tacz:m4a1的换弹冷却都小于3秒
