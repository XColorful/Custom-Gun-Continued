# 免疫子弹实体
> wiki 版本：`26.10.26`.0

## 护甲附魔
> _armor_enchantment.json_

免疫非`pierce_damage`的`bullet_damage`伤害的实体

```json
{
	"replace": false,
	"values": [
	]
}
```

## 无敌附魔
> _invunlerability_enchantment.json_

免疫非`bypass_damage`的`bullet_damage`伤害的实体

```json
{
	"replace": false,
	"values": [
		"minecraft:block_display",
		"minecraft:glow_item_frame",
		"minecraft:interaction",
		"minecraft:item_display",
		"minecraft:item_frame",
		"minecraft:painting",
		"minecraft:text_display"
	]
}
```

# English
> wiki version: `26.10.26`.0

## Armor enchantment
> _armor_enchantment.json_

Entities are immune to `bullet_damage` damage unless it is `pierce_damage`.

```json
{
	"replace": false,
	"values": [
	]
}
```

## Invulnerability enchantment
> _invulnerability_enchantment.json_

Entities are immune to `bullet_damage` damage unless it is `bypass_damage`.

```json
{
	"replace": false,
	"values": [
		"minecraft:block_display",
		"minecraft:glow_item_frame",
		"minecraft:interaction",
		"minecraft:item_display",
		"minecraft:item_frame",
		"minecraft:painting",
		"minecraft:text_display"
	]
}
```
