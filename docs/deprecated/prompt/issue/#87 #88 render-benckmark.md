- 持枪帧时间排序：**cgc1 1.431 < tacz1 1.540 < tacz2 1.625 < cgc2 1.657 ms**。
- 唯一受控同代比较（tacz1 vs cgc1，同为 Forge 47.4.23）：空手 −0.2%、/clear +0.4% 都在噪声内，**只有持枪步骤有实质差异，cgc1 高 7.63%**（超出重复噪声）。
- 标准场景最低仍有 3.66 倍 165Hz 余量，差异在该刷新率下不可见；**multi 是唯一贴近上限的场景**：tacz 组 2.76–5.12 倍余量，cgc 组 0.92–1.04 倍并贴住 165Hz（Maximum 163.6/165.9），绝对差值不可比。
