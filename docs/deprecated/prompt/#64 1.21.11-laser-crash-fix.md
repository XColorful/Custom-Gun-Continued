## 根因（日志里写得很直接）

```
Couldn't compile pipeline (customgun:laser_beam_entity):
com.mojang.renderpearl.util.ShaderCompileException: Unable to find shader defined uniform (Sampler1)
  at com.mojang.renderpearl.frontend.shaders.PipelineBuilder.generateBackendCreateInfo(PipelineBuilder.java:277)

   - customgun:laser_beam_entity
  at net.minecraft.client.renderer.ShaderManager.apply(ShaderManager.java:209)
```

26.3 的 renderpearl 管线预编译多了一条校验：**着色器里用到的每个 uniform/sampler，都必须在管线的 bind group layout 里声明**，缺了就在资源重载阶段抛异常 → 启动黑屏。

而 26.3 的 `core/entity.vsh`：

```glsl
#if !defined(EMISSIVE) && !defined(OIT_ALPHA_ONLY)
    lightMapColor = sample_lightmap(Sampler2, UV2);      // EMISSIVE 关掉这条
#endif
#if !defined(NO_OVERLAY) && !defined(OIT_ALPHA_ONLY)
    overlayColor = texelFetch(Sampler1, UV1, 0);         // 只被 NO_OVERLAY 守卫 → 仍然要用
#endif
```

我们的 `LASER_BEAM_ENTITY_PIPELINE` 建自 `ENTITY_EMISSIVE_SNIPPET`（只带 `SAMPLER0`），`EMISSIVE` 只关掉了 Sampler2 那条，Sampler1 还在用 → 校验失败。vanilla 的 `ENTITY_TRANSLUCENT_EMISSIVE` 在 26.3 同样补了 `.withBindGroupLayout(BindGroupLayouts.SAMPLER1)`。
