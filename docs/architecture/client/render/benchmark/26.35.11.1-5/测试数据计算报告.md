# 测试数据计算报告（CGC 1.20.1 · 26.35.11.1-5：B1-b 第一人称阶段验收）

**数据**：本目录 4 组，每组 = 一次独立启动（n=4）。每组含 Afterburner 与 F12 内置探针两次运行，**时间上不重叠**（先 AF 10 s，再 F12 10 s）。
- `cgc1 (N).txt`：Afterburner，4 步静止帧时间 = 空手 / `tacz:ak47` / `tacz:m4a1` 裸配 / `tacz:m4a1` 满配
- `cgc1-builtin (N).txt`：F12，3 段换弹 = ak47 / m4a1 裸配 / m4a1 满配；每段 10 s，0/3/6 秒各触发一次换弹，段尾空闲

**口径**：帧时间 = 1000 / FPS；均值 ± 1 样本标准差。Afterburner 与 F12 分开，F12 帧时间含探针开销，只用于同口径比较。CGC 成本取「同一次运行内 步骤帧时间 − 空手帧时间」，避免进程级空手基线噪声。
**环境**：GTX 1660 SUPER / i5-9400F / 1080p165；Forge 47.4.23 + Embeddium + Oculus（未开光影包）；超平坦虚空、渲染距离 2、模拟距离 5；见 [标准.txt](./标准.txt)。
**复现**：`python analyze.py`。

## 3. 分块拓扑的收敛情况

- **`Bake rebuilds` 整段为 0.00/帧**：3 次换弹的段落里，`Static bake` 只在 **0.0%–0.1% 的帧**上命中（第一次换弹切开脏骨架的那几帧），单次 0.08–1.33 ms；第二次、第三次换弹一次都没重烘。
- 块一旦切开，动画只改块根的矩阵，脏子树的顶点不再重新生成——这是 CGC −71% 的直接来源。
- 满配的单次烘焙反而最便宜（均值 0.104 ms，裸配 0.571 ms）：它的动画骨架被打得更碎，块更小。

## 4. 剩余成本：draw 变成了新的地板

满配 CGC 0.570 ms 的构成（探针区间有嵌套，只作量级）：

|项|耗时|性质|
|---|---:|---|
|Model render total|0.418|块绘制 + 委托；枪体与瞄具配件模型都在内|
|其中 delegate（配件 / 手臂 / 火焰 / 文字）|0.185|仍是即时路径|
|Scope render（模板窗口 + 5 次 pass）|0.189|与 Model render total 重叠（内层含瞄具模型渲染）|
|状态更新 / 数据刷新|0.055|每帧|
|`Draw calls`|43.0|含整帧约 8 次非 CGC draw，CGC 约 35 次|

三项相加 0.66 大于 CGC 0.570，是因为探针区间有嵌套；只作量级参考。

- 35 次 CGC draw × 约 7–8 µs ≈ **0.27 ms**，是剩余成本里最大的单项之一。分块把「逐顶点生成」换成了「每块一次 draw」，与 multi 的 draw 地板同性质。
- 裸配 / ak47 的 `Draw calls` 是 21–24（CGC 约 13–16 次），满配的 43 主要来自瞄具模板 pass 与更多动画骨骼切出的块。
- 瞄具模板 0.189 是满配第二大的单项，比方案的 ≈0.06 预估高：模板 pass 仍是「一个 pass 一次 draw + 状态」，只省掉了顶点生成。

## 6. 结论

1. **B1-b 达标**：满配帧时间 −56%、CGC −71%；裸配 −41% / −66%。静止 CGC 0.214 / 0.540 低于目标，换弹段也没有明显回退（相对静止增量约 +0.03 ms）。
2. **顶点生成已从第一人称消失**：`Geometry traverse` 无命中、`Upload bytes` −89%、`Cubes submitted` 只剩附加弹匣与首次烘焙。
3. **换弹不再整帧退回**：`MAG_ADDITIONAL` 单节点即时绘制生效，3 次换弹的段落里烘焙只发生在第一次换弹的前几帧。
4. **剩下的瓶颈是 draw 与 delegate**：满配 35 次 CGC draw ≈0.27 ms + 瞄具模板 0.189 + delegate 0.185。块数现在是可调项（切得越多 draw 越多），瞄具模板 pass 的固定开销也没被烘焙消掉。
5. **未测**：多人 / 世界实例、切枪与检视动作（开光影与换弹后的待机已由下列子批次补齐）。

## 7. 异常与说明

- 空手基线的 sd 偏大（0.790 ± 0.040）：第 3 次启动的空手是 0.848 ms，其余三次 0.757–0.779；因此 CGC 一律用**同次运行相减**，并给出逐次增量的 sd。
- 每个 Afterburner 文件只有 4 条记录，标准里写 7 步：第 3/5/7 步（换弹）是独立的 F12 采集，不在 Afterburner 记录里。
- `Distinct nodes` / `Dirty nodes` / `Dirty cubes` 这组探针在 B1-b 后**只统计即时块与即时管线**：本批 ak47 46 个、裸配 / 满配 22 个，远小于模型节点数（361 / 613 / 1578）。分块路径的失效改由 `Bake rebuilds` / `Static bake` 反映，不要再拿这组值算脏比例。
- F12 帧时间（1.246 / 1.163 / 1.482）与 AF（0.991 / 1.004 / 1.330）不同口径，不能相减当探针开销：F12 段含 3 次换弹，AF 是静止。
