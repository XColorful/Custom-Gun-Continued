## 1. 问题原因

红点瞄准镜镜片（`scope_body/lens` 里那个 `1.126×1.2229×0`、z=-1.3125 的薄片）材质是「透明 + 中间红点」，并且只有 **"north" 单面**（朝向枪口前方）。

在 1.20.1–1.21.11，这个面从射手眼睛方向看是背向的，会被**背面剔除（backface culling）**挡掉，所以第一人称看不见；第三人称从枪口前方看则能看到红点。

26.1.2 原版把 `entityCutout` 渲染管线改成了 `.withCull(false)`（关闭背面剔除）并加了 `PER_FACE_LIGHTING`。CGC 的枪/配件模型都通过 `ClientRenderUtils.RenderType_.entityCutout` 走这个 `entityCutout`，于是镜片这个单面薄片变成**双面渲染**，射手从背面也能看到红点方片。

> 你之前猜测是「模板测试没挡住配件本身」，实际不是模板问题，而是原版 26.1.2 把 `entityCutout` 的背面剔除关掉了。

## 3. CGC 移植情况

我对照了 `D:\Github\TACZ` 源码：CGC 的 `_AttachmentModelRender` / `_GunModelRender` 与 TaCZ 的 `BedrockAttachmentModel` / `BedrockGunModel` 逐行一致，`renderSight` / `renderOcularStencil` / `renderDivisionOnly` 的 stencil 逻辑、`depthMask(false)`、`disableDepthTest()` 都是忠实移植。PipelineModifier 三处映射（`NO_COLOR_WRITE`/`NO_DEPTH_WRITE`/`NO_DEPTH_TEST`）和 `StencilFunctionHelper` 的 CompareOp 映射也都正确。

真正的差异是**平台 API 变化**：26.1.2 把 `entityCutout` 语义改了（cull 关闭），并新增了 `entityCutoutCull`（cull 开启）作为旧语义的等价物。这不是 CGC 移植错误。

## 4. 修改内容

只改了一行：[ClientRenderUtils.java:117](app://localhost/epitaxy/core/src/main/java/dev/xcolorful/customgun/client/util/ClientRenderUtils.java:117)

```java
return RenderTypes.entityCutout(textureLocation);
```

→

```java
return RenderTypes.entityCutoutCull(textureLocation);
```

26.1.2 的 `entityCutoutCull`（`ENTITY_CUTOUT_CULL` 管线，无 `.withCull(false)`、无 `PER_FACE_LIGHTING`）等价于 1.21.11 的 `entityCutout`。

**需你确认**：这是一处平台 API 变更，我直接改在了 CGC 自己的 `RenderType_` 包装类里。这个包装类同时服务于枪、配件、弹药、弹壳、物品 GUI 等所有 `entityCutout` 渲染——但 1.21.11 它们本来就是 cull 开启，所以这是恢复原行为，对其它场景无可见影响。
