# 测试数据计算报告（CGC 1.20.1 · b1-a-6：multi 空展示框场景基线）

**数据**：本目录 8 次独立启动。`1–4` 是加 b1-a-7 探针之前的构建，`5–8` 是之后；本报告以 **5–8（n=4）** 为准，1–4 只用来确认探针在未采集时不引入开销。
**场景**：9 个石头 + 9 个空展示框，空手；与 [`b1-a-5`](../b1-a-5/测试数据计算报告.md) 的 multi 场景只差展示框里有没有枪。
**口径**：帧时间 = 1000 / FPS；均值 ± 1 样本标准差。Afterburner 与 F12 分两次运行，同一段数据里两者不重叠。见 [标准.txt](./标准.txt)。
**复现**：`python analyze.py`。

## 1. 结果

|项|值|
|---|---:|
|AF 帧时间|**0.864 ± 0.032 ms**|
|AF 1% low|530.3 FPS|
|F12 帧时间|0.899 ± 0.041 ms|
|`GPU frame busy`|0.817 ± 0.037 ms|
|`Draw calls`|9 / 帧|
|`Upload bytes`|30.8 KB / 帧|
|`Allocated bytes`|93.1 KB / 帧|
|CGC 相关计数|全部为 0（场景里没有枪）|

加探针前（1–4）：AF 0.863 ± 0.024 ms、F12 0.899 ± 0.033 ms，与 5–8 在噪声内一致——**新增的探针在未采集时不产生可测开销**。

## 2. 用途：坐实 b1-a-5 的「0.97 ms 未归因项」

`b1-a-5` 的 multi（9 把满配展示框）帧时间 2.146 ms、CGC 1.199 ms，两者之差 0.947 ms 当时只能按旧批次的 0.866 ms 基线**推断**为场景基线。本批在同一场景中直接测到：

|项|值|
|---|---:|
|9 个空展示框（本批）|**0.864 ms**|
|9 把满配展示框去掉 CGC（b1-a-5）|0.947 ms|
|差|+0.083 ms（9.6%）|

0.947 − 0.864 ≈ **0.08 ms**，与「空展示框里多放 9 把枪带来的非 CGC 附加成本（展示框实体、光照、剔除框等）」同量级。**结论：0.97 ms 不是 CGC 的 GPU 绘制成本，multi 的帧时间 ≈ 场景基线 0.864 + CGC 1.199 + 少量场景附加。**

`GPU frame busy` 0.817 与帧时间 0.899 的比值（91%）仍然只能说明命令跨度，不能当 GPU 利用率用。

## 3. 这条基线的边界

- **不可与 `26.35.11.1-2` 的 0.852 ms 混用**：那是渲染距离 5、裸枪展示框的旧场景；本批是渲染距离 2 的虚空场景，实测 0.864 ms 恰好接近，但不是同一口径。
- 场景基线随渲染距离、方块数量与实体数变化，B2 验收时如果换了场景要重测这一条。
- 本批没有枪，脏节点 / `Distinct RenderTypes` 等计数为 0 属预期。
